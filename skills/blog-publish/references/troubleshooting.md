# 故障排查

## 先看三样东西

1. 命令输出最后一行（`失败：…` 后面的具体原因）
2. `runs/<时间>-<平台>-<文件名>/` 里最后一张截图（`*-after-confirm.png` / `dry-run-final.png`）
3. `runs/.../result.json`（如果已经生成）

截图比日志有用：大部分失败在截图里一眼能看出来（弹窗没开、标签没选上、页面停在登录页）。

## 症状对照表

| 症状 | 大概率原因 | 处理 |
| --- | --- | --- |
| `掘金/知乎 未登录，先运行 login` | profile 新建或登录过期 | `blog-publish login` |
| `Chrome 未能在 30s 内开放调试端口` | 9222 被占用，或 Chrome 路径找不到 | 关掉旧窗口；设 `CHROME_PATH` 指向 chrome 可执行文件 |
| `点击「发布」后没有出现发布设置面板` | 页面没加载完，或「发布」按钮被其它层挡住 | 重跑一次；连续失败就看截图确认页面停在哪个状态 |
| `标签没有选中（掘金要求至少一个标签）` | 账号标签配额为 0，或下拉没展开 | 换一个已有标签；确认账号等级 |
| `摘要实际只写入 N 字` | 摘要框被 React 重置 | 重跑；仍失败则把 `summary` 调到 60~80 字 |
| `发布前标题被改动` | 编辑器异步回写标题 | 缩短标题重试；这是保护，不是 bug |
| `未出现知乎发布弹窗` | 少数账号不会弹设置框 | 工具已改为"URL 判定"，出现此错说明点击没生效，看截图 |
| `发布后未能确认文章地址` | 发布成功但页面没跳转 | 去个人主页看最新文章；有则用 `mark` 登记后跳过 |
| `回读校验：有问题 → 正文过短` | 刚发布页面还没渲染完 | 工具已重试 60s；仍失败就人工打开链接确认 |
| 幂等提示"跳过" | 相同正文已在 `publish-log.json` 里 | 确认要重发就加 `--force` |

## 手动取证

想确认某次到底发了什么：

```bash
# 看发布记录
cat ~/.blog-publisher/publish-log.json

# 看最近一次产物
ls -la runs/ | tail -3
```

想确认 Chrome 里到底登录了谁：

```bash
blog-publish preflight
```

## 清理

- 删除测试文章：`blog-publish rollback --url <链接>`（只对自己账号有效）
- 重置登录态：删掉 `~/.blog-publisher/profiles/chrome`，重新 `login`
- 重置幂等记录：删掉 `~/.blog-publisher/publish-log.json`

## 什么时候该改代码

页面改版（选择器失效）才会需要改 `src/platforms/*.mjs`。判断方法：截图显示页面结构和你记忆里不一样，且报错集中在"找不到元素"。
改之前先跑 `--dry-run` 复现，改完再跑一次 `--dry-run` 验证，最后才真发。
